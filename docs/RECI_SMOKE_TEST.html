How to Use This Document

Work through each scenario in order. For each step: perform the action, compare the result to the Expected column, then tick Pass or Fail. If a step fails, note the error in the Notes column before continuing to the next scenario.

P Step passed — result matches expected
F Step failed — note the deviation
Manual checkbox to tick off
Before starting: Confirm both servers are running (pnpm exec turbo run dev --parallel), Supabase is awake (check Supabase Dashboard), and Stripe CLI is forwarding webhooks (stripe listen --forward-to localhost:3000/api/webhooks/stripe).

6 Scenario 6 — Local AI Vision Adapter (LLaVA / Ollama)
Feature: Swap vision model from Anthropic Claude to local LLaVA via env var
Client concern addressed: API cost at scale — high-volume fleets can use local models at zero per-call cost
Env file: apps/web/.env.local
Prerequisites
  • Ollama installed locally: https://ollama.com
  • LLaVA model pulled: run ollama pull llava in a terminal
  • Ollama running: ollama serve (listens on port 11434 by default)
Skip this scenario if Ollama is not installed. The Anthropic provider (default) was already tested in Scenarios 4 and 5. This scenario only verifies the swap mechanism.
#ActionExpected ResultPass / FailNotes
1Edit apps/web/.env.local — add:
AI_VISION_PROVIDER=openai-compatible
AI_VISION_BASE_URL=http://localhost:11434/v1
AI_VISION_MODEL=llava		File saved. No syntax errors.P F
2Restart the web dev server (kill port 3000, then pnpm exec turbo run dev)Server starts. Console shows no startup errors.P F
3POST a licence image to /api/ai/licence (via browser booking flow or curl with a base64 image)Response received (may take 5–30 seconds with local LLaVA). JSON has status: "pending" and extracted fields. No Anthropic API calls made (verify in Anthropic console — no new usage).P F
4Check server logs (terminal running pnpm dev) for any errorsNo "fetch failed" or "connection refused" errors. If Ollama returned a result, logs show the route completed successfully.P F
5Revert .env.local: remove the 3 added lines (or set AI_VISION_PROVIDER=anthropic). Restart server.Server restarts. Anthropic is the active provider again. Subsequent vision calls use Claude.P F
